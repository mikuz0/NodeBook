# План: Рабочий раздел components (CRUD) + просмотр modules/standards

## Текущее состояние

SectionWindow: TreeView + titleLabel + jsonArea (read-only JSON) + Refresh/Close.
Executor для фонового I/O уже есть (демон-потоки).

## Изменения

### Шаг 1. Форма редактирования (components) + read-only (modules/standards)

**Заменить** jsonArea на панель формы:
- name (TextField, editable для components)
- description (TextArea, editable для components)
- type (Label, read-only)
- slug (Label, read-only)
- Save / Revert кнопки (активны только при dirty + выбранном узле)
- Статус-бар внизу (успех/ошибка)

**При выборе узла:** загрузить NodeRef.meta в форму.
**Save:** NodeRepository.save(path, meta.copy(name, description)) в фоне.
**Revert:** перечитать с диска.
**Для modules/standards:** поля isEditable=false, кнопки скрыты.

### Шаг 2. Контекстное меню + кнопки создания

**TreeView контекстное меню (правый клик):**
- на SECTION: New type ( CATEGORY )
- на CATEGORY: New manufacturer ( MANUFACTURER )
- на MANUFACTURER: New component ( COMPONENT )
- на COMPONENT: Delete
- на SECTION/CATEGORY/MANUFACTURER (не корень): Delete

**Кнопки на панели:** дублируют контекстное меню (New type / New manufacturer / New component / Delete).

**Диалог создания:** модальный Dialog с полями name (обязательно) + description.
**После создания:** listChildren(parent), раскрыть родителя, выделить новый узел.

### Шаг 3. Удаление

- Подтверждение через UiUtils.confirmAlert
- Корень раздела (type=SECTION) удалять нельзя
- NodeRepository.delete(path) в фоне
- После успеха: listChildren(parent), снять выбор

### Шаг 4. modules/standards — только просмотр

- Дерево строится (loadTree)
- Форма read-only (isEditable=false, кнопки скрыты)
- Контекстное меню создания/удаления скрыто
- Refresh работает

### Шаг 5. Refresh с сохранением раскрытия/выбора

- Сохранить expanded Paths и selected Path
- После перестройки: восстановить expanded + selection

### Шаг 6. Тесты

- Добавить тест на цепочку SECTION→CATEGORY→MANUFACTURER→COMPONENT
- ./gradlew test — зелёный

### Диалог создания
```kotlin
private fun showCreateDialog(parentDir: Path, expectedType: NodeType) {
    val dialog = Dialog<Pair<String, String>>()
    dialog.title = "New $expectedType"
    dialog.headerText = "Enter name for new node"
    dialog.dialogPane.buttonTypes.addAll(ButtonType.OK, ButtonType.CANCEL)

    val nameField = TextField()
    nameField.promptText = "Name (required)"
    val descArea = TextArea()
    descArea.promptText = "Description (optional)"

    dialog.dialogPane.content = VBox(10.0, nameField, descArea)

    dialog.resultConverter { button ->
        if (button == ButtonType.OK) Pair(nameField.text, descArea.text) else null
    }

    dialog.showAndWait().filterNotNull().forEach { (name, desc) ->
        if (name.isBlank()) {
            UiUtils.errorAlert(stage, "Error", "Name is required")
            return@forEach
        }
        val slug = NodeRepository.generateUniqueSlug(parentDir, name)
        val meta = NodeMeta(
            type = expectedType,
            name = name,
            description = desc
        )
        // Create in background
        val task = object : Task<Unit>() {
            override fun call() {
                when (expectedType) {
                    NodeType.CATEGORY, NodeType.MANUFACTURER -> {
                        NodeRepository.createContainer(parentDir, slug, meta)
                    }
                    NodeType.COMPONENT -> {
                        NodeRepository.createLeaf(parentDir, slug, meta)
                    }
                    else -> throw IllegalArgumentException("Unexpected type: $expectedType")
                }
            }
            override fun succeeded() {
                // Refresh parent children
                refreshParentChildren(parentDir)
                statusLabel.text = "Created: $name"
            }
            override fun failed() {
                UiUtils.errorAlert(stage, "Create Error", exception?.message ?: "Unknown")
            }
        }
        executor.submit(task)
    }
}
```

### Refresh с сохранением состояния (Step 5)
```kotlin
private fun refreshSection() {
    val selectedNodeRef = treeView.selectionModel.selectedItem?.value
    val expandedPaths = mutableSetOf<Path>()
    collectExpandedPaths(treeView.root, expandedPaths)

    // Reload tree
    val sectionDir = currentSectionDir ?: return
    val task = object : Task<List<NodeRef>>() {
        override fun call() = NodeRepository.loadTree(sectionDir)
        override fun succeeded() {
            buildTree(value ?: emptyList())
            // Restore expanded
            restoreExpanded(treeView.root, expandedPaths)
            // Restore selection
            selectedNodeRef?.let { nr ->
                val idx = findNodeInTree(treeView.root, nr.path)
                if (idx >= 0) treeView.selectionModel.select(idx)
            }
            statusLabel.text = "Refreshed"
        }
    }
    executor.submit(task)
}

private fun collectExpandedPaths(item: javafx.scene.control.TreeItem<TreeItemData>?, paths: MutableSet<Path>) {
    item?.let {
        it.value?.nodeRef?.path?.let { p -> paths.add(p) }
        collectExpandedPaths(it.parent, paths)
    }
}

private fun restoreExpanded(item: javafx.scene.control.TreeItem<TreeItemData>?, expandedPaths: Set<Path>) {
    item?.let {
        it.value?.nodeRef?.path?.let { p ->
            if (p in expandedPaths) it.isExpanded = true
        }
        it.children.forEach { restoreExpanded(it, expandedPaths) }
    }
}

private fun findNodeInTree(item: javafx.scene.control.TreeItem<TreeItemData>?, targetPath: Path): Int {
    // BFS to find index
    val queue = java.util.ArrayDeque<javafx.scene.control.TreeItem<TreeItemData>>()
    queue.add(item)
    var idx = 0
    while (queue.isNotEmpty()) {
        val current = queue.removeFirst()
        if (current.value?.nodeRef?.path == targetPath) return idx
        current.children.forEach { queue.add(it) }
        idx++
    }
    return -1
}
```
