# План: Исправление корректного завершения приложения

## Найденные места создания потоков/пулов

| Файл | Место | Проблема |
|------|-------|----------|
| `BooksController.kt:16` | `Executors.newFixedThreadPool(2)` | Не-демон потоки, нет shutdown |
| `SectionWindow.kt:68` | `Executors.newSingleThreadExecutor()` в `openSection()` | Новый executor на каждый вызов, не выключается |
| `SectionWindow.kt:99` | `Executors.newSingleThreadExecutor()` в `createTreeItem()` | Новый executor на каждый контейнер-узел, не выключается |
| `MainApp.kt` | Нет `stop()` | JVM не завершается |

## Изменения

### Шаг 1: BooksController.kt — демон-потоки + shutdown()

**Было:**
```kotlin
private val executor = java.util.concurrent.Executors.newFixedThreadPool(2)
```

**Стало:**
```kotlin
private val executor = java.util.concurrent.Executors.newFixedThreadPool(2) { r ->
    Thread(r, "books-io").apply { isDaemon = true }
}

fun shutdown() {
    log.info("BooksController shut down")
    executor.shutdownNow()
}
```

### Шаг 2: MainApp.kt — переопределить stop()

**Добавить:**
```kotlin
override fun stop() {
    if (::controller.isInitialized) controller.shutdown()
    super.stop()
}
```

### Шаг 3: SectionWindow.kt — единый executor + shutdown

**Было:** 2 места с `Executors.newSingleThreadExecutor()` (openSection + createTreeItem)

**Стало:**
```kotlin
private val executor = java.util.concurrent.Executors.newFixedThreadPool(2) { r ->
    Thread(r, "section-io").apply { isDaemon = true }
}

// В init:
stage.setOnCloseRequest { executor.shutdownNow() }

// В openSection: executor.submit(task) вместо newSingleThreadExecutor().submit(task)
// В createTreeItem: executor.submit { ... } вместо newSingleThreadExecutor().submit { ... }
```

## Проверка

```bash
./gradlew clean build   → BUILD SUCCESSFUL
./gradlew test          → 15 тестов зелёные
./gradlew run           → закрыть крестиком → процесс завершается, терминал возвращает приглашение
```

## Решения по-defaults

- `shutdownNow()` в `stop()` через `BooksController.shutdown()`
- Демон-потоки: `Thread(r, "books-io").apply { isDaemon = true }` и `Thread(r, "section-io").apply { isDaemon = true }`
- `if (::controller.isInitialized)` в `stop()` на случай падения старта
- SectionWindow — один executor, выключение в `stage.setOnCloseRequest`
- Логирование остановки на уровне INFO
