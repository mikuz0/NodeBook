# NodeBook — План первой итерации

## Контекст

Текущий проект — пустой JavaFX-скелет (Hello World, название `git-gui`, пакет `com.pandakind.nodebook`). Нужно полностью перестроить его в **NodeBook** — менеджер баз знаний на JavaFX + Kotlin.

**Ключевое решение:** JGit-зависимости не нужны — убираем. Все остальные зависимости (kotlinx.serialization, SLF4J/Logback, JUnit 5, JavaFX) сохраняем.

## Шаг 3. Менеджер книг в `nodebook-app` (JavaFX)

### Пакет `ru.nodebook.app`

| Файл | Содержание |
|------|-----------|
| `MainApp.kt` | `class MainApp : Application()` — при старте: `AppPaths.initConfigDir()`, `SettingsStore.load()`, если workspace задан — установить. Запускает `BooksView`. |
| `BooksView.kt` | FXML-View (или programmatic): секция Workspace (TextField + Choose button), секция New KB (TextField + Create), statusLabel, `ListView<KnowledgeBaseInfo>`, кнопки разделов (Components, Modules, Standards) |
| `BooksController.kt` | `setWorkspace(path)` — сохранить, загрузить книги в фоне (`Task`); `loadBooks(workspace)` — `KnowledgeBaseRepository.scan`; `createBook()` — валидация, `KnowledgeBaseRepository.create` в фоне, перезагрузка списка, авто-выбор; `updateSectionButtonsState()` |

### Архитектура UI
- **Без FXML** — всё программно через JavaFX Scene Builder API (VBox/HBox/FlowPane), как в prompt описаны callback-свойства
- `BooksView` имеет callback-свойства: `var onOpenSection: ((String) -> Unit)? = null`
- Кнопки разделов вызывают `onOpenSection.invoke(sectionName)`
- Заголовок окна: `NodeBook — Knowledge Base Manager`, min size 700×500

### Команда проверки
```bash
./gradlew :nodebook-app:build
```

## Шаг 4. Каркас окна раздела в `nodebook-ui`

### Пакет `ru.nodebook.ui`

| Файл | Содержание |
|------|-----------|
| `BookAware.kt` | `interface BookAware { fun showWindow(); fun openSection(bookPath: Path, section: String); fun getStage(): Stage? }` |
| `SectionWindow.kt` | `class SectionWindow : BookAware` — `TreeView<NodeRef>` слева (загрузка через Task), справа — Label заголовка + TextArea с JSON NodeMeta, кнопки Refresh и Close |
| `UiUtils.kt` | `errorAlert(title, message)`, `confirmAlert(title, message)`, path styling |

### Структура SectionWindow
```
┌─────────────────────────────────────────────────┐
│  Section: components          [Refresh] [Close] │
├──────────────────┬──────────────────────────────┤
│                  │                              │
│  TreeView        │  Label: selected node name   │
│  (left, ~300px)  │                              │
│                  │  TextArea (readonly):         │
│                  │  { JSON NodeMeta }            │
│                  │                              │
└──────────────────┴──────────────────────────────┘
```

### В MainApp
```kotlin
val sectionWindows = mutableListOf<SectionWindow>()
// При нажатии кнопки раздела:
val win = SectionWindow()
sectionWindows.add(win)
win.openSection(book.path, sectionName)
win.onClose = { sectionWindows.remove(win) }
```

### Команда проверки
```bash
./gradlew :nodebook-ui:build
./gradlew build
```

## Шаг 5. End-to-end проверка (ручной сценарий)

1. Запустить `./gradlew :nodebook-app:run`
2. Выбрать пустую папку как workspace
3. Создать книгу `demo`
4. Проверить на диске:
   - `workspace/demo/book.json` — корректная структура
   - `workspace/demo/components/node.json` — `{"type":"SECTION","slug":"components",...}`
   - `workspace/demo/modules/node.json`
   - `workspace/demo/standards/node.json`
5. Открыть раздел `components` — дерево показывает один узел `components` (SECTION)
6. Перезапустить — workspace и книги восстановились из `~/.config/nodebook/settings.json`

## Принятые решения по умолчанию

- JavaFX 21 (версия из gradle.properties)
- kotlinx.serialization 1.8.0
- Всё программно (без FXML) — проще для multi-module и нет зависимостей от ресурсов
- `node.json` для контейнеров, `<slug>.node` для листов
- XDG-конфиг: `~/.config/nodebook/settings.json`
- Логирование: logback, INFO, с временем/уровнем/логгером
